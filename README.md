# digital-court-search-judgement
A web-based Digital Court Judgment Search System developed using Python and Flask. This project allows users to search available court judgments using keywords and displays matching judgment records through a simple and user-friendly web interface.

## 1. Project Introduction
The Digital Court Judgment Search System is a web-based application that helps users search for court judgments using keywords.

## 2. Objectives
- To make searching court judgments easier.
- To display relevant judgment results.
- To reduce the time required to find legal information.

## 3. Technologies Used
- Python
- Flask
- HTML
- CSS
- PyCharm

## 4. Installation Instructions

Install Flask:

```bash
pip install flask
```

## 5. How to Run the Project

1. Open the project in PyCharm.
2. Run app.py.
3. Open your browser.
4. Enter http://127.0.0.1:5000.
5. Enter a keyword and click Search.
